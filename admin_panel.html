GitHub Sync Inactive!

Your live website server is not authorized to push files to GitHub. Any changes you make will only exist temporarily in the server's RAM/ephemeral disk and will be lost next time the server redeploys or restarts.

To resolve this: Go to the Settings tab and enter your GitHub Personal Access Token (PAT) and repository details, or define the GITHUB_TOKEN and GITHUB_REPO environment variables in your hosting dashboard (e.g., Render).

How to Update Your Site

  1. Make your changes in the editor below (Add, Edit, Delete).
  2. Click the "Download Config" (and/or "Markdown" for blogs) button in the respective tab.
  3. A file (certificates_data.js, skills_data.js, projects_data.js, or blog_data.js) will download.
  4. Replace the existing file in your project folder: assets/js/ with this new one (and place markdown files in blogs/).
  5. Refresh your portfolio website to see the changes!

Interactive Help & Documentation

1. How Auto-Saving Works ⚡

All sections of your website (Certificates, Technical Skills, Projects, and Blog Posts) now support real-time automatic saving to the live backend server.

  • Forms: When you submit any edit form or click "Save to List", the data is immediately sent to the API, writing the changes to disk.
  • Reordering & Deletion: Clicking the Up / Down arrows to change layout hierarchy or clicking Delete instantly updates the server files.
  • GitHub Sync: If you have GitHub Auto-Sync configured (via settings or server environment variables), the backend immediately commits and pushes the updated configuration files to your GitHub repository in the background.

2. GitHub Integration Setup ⚙️

To make sure changes appear on your live site, you have two options to authorize the backend server to write to GitHub:

  1. Option A (Recommended for Multi-Device Sync): In your Render Dashboard, set these Environment Variables:
    • GITHUB_TOKEN = Your Personal Access Token (PAT).
    • GITHUB_REPO = krsna016/my-portfolio.
    • GITHUB_BRANCH = master.
    This lets you write blogs and update listings from any phone or browser.
  2. Option B (Local Browser Sync): Navigate to the Settings tab here in the admin panel and save your PAT credentials. This stores the details in your current browser's local storage.

3. Manual Backups (Download Config & Markdown) 💾

Under each editor panel tab, there are fallback buttons (e.g. Download Config / Download Markdown):

  • Download Config: Generates and downloads the Javascript files (e.g. certificates_data.js) containing the raw array structure. You can use these to manually restore your site if the server is offline.
  • Download Markdown: Downloads the compiled markdown text file of your blog articles.
